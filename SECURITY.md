
# MotoTrip Security Policy

## Supported Versions

Only the latest released version of MotoTrip receives security updates.

## Reporting a Vulnerability

If you discover a security vulnerability, please report it privately.

**Email:** satish9648291@gmail.com

You can also use GitHub's private vulnerability reporting feature, when enabled.

Please include:
- Description of the vulnerability
- Steps to reproduce
- Affected feature or version
- Screenshots or error logs, if available

## Responsible Disclosure

Please do not publicly disclose security vulnerabilities before they have been reviewed.

Never post passwords, private user data, signing keys or sensitive credentials in public GitHub Issues.

## Security Updates

Confirmed vulnerabilities will be reviewed and prioritized based on severity.

Thank you for helping keep MotoTrip secure.
