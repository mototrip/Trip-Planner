GITHUB UPLOAD:
1. Back up existing local data first (Trips > Export backup).
2. Extract this ZIP, upload its files to GitHub repo root (do NOT upload ZIP itself).
3. Replace existing matching files and commit; added files must also be present.
4. Open app once and test one **test** Shared Ride invite on each phone/browser before public launch.

NOTES:
- WhatsApp / SMS require compatible apps/phone support.
- More Apps uses native Web Share API where supported; desktop browsers fallback to copying link.
- Camera requires HTTPS and permission.
- Firebase Auth + Firestore + Firestore rules are still required for real-time group sync.
- QR / sharing is not full permission management. Anyone with the invite may be able to join; share only with trusted friends.
