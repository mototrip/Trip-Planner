2) https://github.com/mototrip/Trip-Planner kholo, apne account se sign in karo.
3) main branch par Add file > Upload files dabao.
4) Extracted folder ke ANDAR ki SAARI files select karke upload karo; folder ko ZIP ke form mein mat upload karna.
5) Neeche Commit changes dabao. Purani same-name files overwrite/replace ho sakti hain.
6) https://mototrip.github.io/Trip-Planner/ open karna. Naya version load na ho to refresh/clear cache.
